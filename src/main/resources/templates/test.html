Cách lấy access token
  1. Vào Graph API Explorer, đăng nhập bằng tài khoản Facebook có quyền trên tài khoản quảng cáo.
  2. Chọn (hoặc tạo) một ứng dụng Meta, ở mục quyền thêm ads_read, bấm Generate Access Token.
  3. Dán token vào ô trên. Token này hết hạn sau khoảng 1–2 giờ; dùng lâu dài thì tạo token của System User trong Business Settings.
  4. Mã tài khoản quảng cáo là số trên thanh địa chỉ Ads Manager (act=...), thêm tiền tố act_.
